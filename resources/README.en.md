# Argent Studio guide

Open a project or an editable example, select the Argent entry file, then compile. Generated files are available in the build panel.

The structure view shares its source document with the text editor. Select a block to inspect its source; use the connection menu to filter relationships.

Local test transactions use a compiled artifact. Choose an actor and entry, enter state and transaction values, and run the test. Start values are suggestions and may fail contract rules. Expert mode exposes the complete JSON scenario. Tests are local simulations and do not submit transactions to a network.

AI assistance is disabled by default. Enable it in Settings only when needed and configure your own credentials. Review proposed changes before applying them.

Use Duplicate project for a separately named copy. Build history is stored inside the project build directory. Save source edits before switching projects.

See the repository README and the compiler language reference in toolchains/argent-master/docs for development instructions and syntax details.
