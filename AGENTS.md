# Arbeitsanweisungen für Argent Studio

## Parallele Agenten

Nutze bei Arbeitsaufträgen in diesem Projekt automatisch die maximal verfügbare Anzahl paralleler Agenten, einschließlich des Hauptagenten. Warte dafür nicht auf eine erneute Aufforderung des Nutzers.

Teile Umsetzung, unabhängige Prüfung und Tests in klar abgegrenzte Aufgaben auf. Der Hauptagent koordiniert die Arbeit, führt die Ergebnisse zusammen und prüft das Gesamtergebnis. Vermeide konkurrierende Änderungen an denselben Dateien. Beachte das jeweils verfügbare technische Agentenlimit.
